# ChatGPT2API 自定义图片供应商

适配文件：[customProviders/chatgptImage.ts](../customProviders/chatgptImage.ts)。使用 Toonflow 现有的自定义媒体供应商入口，不替换 TF-router、H3 或其他供应商，也不需要修改源码或启动新服务。

## 导入与使用

1. 下载本仓库的 `customProviders/chatgptImage.ts`。
2. 打开 Toonflow「设置 → 媒体模型 → 添加自定义供应商」，选择「文件导入」并导入该文件。
3. 在供应商连接配置中填写 Base URL 和自己的 API Key，然后保存。默认 Base URL 为 `http://124.220.13.249:3010/v1`，地址须包含 `/v1`。
4. 新建图片生成节点，选择「ChatGPT2API 图片（自定义）」下的模型，输入提示词、选择比例和 `1K` 档位，再手动生成。

供应商文件中的 API Key 默认留空。仓库不包含本机设置、登录凭据、Key 池或测试图片；导入文件本身不会生成图片。

## 能力与限制

- 注册 `gpt-image-2`、`gpt-image-2.5`、`gpt-image-2.5-flare` 和 `gpt-image-2.5-sunburst`，名称来自网关，不代表已核实其底层模型身份。
- 仅支持文生图；参考图、蒙版、图片编辑及 `2K/4K` 未启用。
- 支持 `1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`9:16` 和 `16:9`。`1K` 是服务的尺寸档位名称，实际宽高随比例变化，例如 `16:9` 对应 `1920×1088`。
- 默认每次生成一张，接口支持数量 1–4。生成请求只提交一次，网络失败不自动重试，避免重复扣费；超时为 8 分钟，支持用户取消。
- 使用 OpenAI 兼容的 `/images/generations` 接口，支持 Base64 或图片 URL 返回结果。
