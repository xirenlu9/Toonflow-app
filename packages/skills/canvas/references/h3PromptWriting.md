# H3 提示词路由

仅在当前视频节点选择 RunningHub MiniMax H3 时使用。先看素材如何约束生成，再只读一个对应指南：

- 纯文本、单张起始图、首尾帧之间的动作、或以尾帧收束：读取 [基础模式](./h3PromptBase.md)，按 T2VA、I2VA、FL2VA 或 L2VA 选择对应结构。
- 多类参考素材共同约束角色、场景、动作、剪辑或声音：读取 [全参考模式](./h3PromptFullReference.md)，按 Ref2VA 六段结构编写。

不要为了“看起来完整”把全参考模式套到简单镜头；首尾帧模式也不要误当成普通参考图模式。提示词正文保留用户原剧情、对白和画面文字；H3 结构用于明确镜头、素材角色和声音。
